# DSH 深海字符水母背景插件：需求草案

## 目标

为 DSH Web 界面提供可独立安装、开启和关闭的动态背景。开启后，整个应用窗口采用深色、半透明的视觉风格，字符水母动画覆盖侧边栏、聊天主区域、右侧面板和设置页的背景。保留 DSH 原有布局、文案、输入框和所有交互。

## 视觉

- 底色为接近黑色的深海军蓝，四周较暗，底部有微弱青蓝光；叠加几乎不可察觉的细网格和中央蓝色柔光。
- 多只大小、距离和位置不同的水母由方格及 ASCII 字符组成。密集区域使用带底色的字符格，稀疏边缘使用单独的点、短线和字符；字符可以轻微随机变化。
- 水母主体以半透明蓝色、蓝紫色为主，伞体中下部有少量暖金光带；伞缘偏淡青白，触手以淡蓝色为主，少量带暖粉色。亮部有克制的柔和泛光。
- 以 `.`、`*`、`+` 和短横线构成缓慢漂浮、偶尔闪烁的微粒。
- 动画在控件后方呈现。经过文字、输入框或其他主要阅读区域时降低亮度和清晰度，保证内容可读。

## 动态

- 水母伞体快速收缩、缓慢舒张；收缩时变窄、变高并略微变暗，舒张时变宽、变扁。
- 每次收缩带来轻微前进或上浮，随后惯性滑行、逐渐减速；触手和口腕延迟摆动。
- 不同水母的相位、速度和尺度错开，避免整齐同步或明显重复。
- 星点缓慢上浮，亮度轻微变化。动画应连续平滑；原帖的“每隔 0.5 秒截图”仅描述展示方式，并非动画帧率。

## DSH 集成

- 背景绘制层铺满应用视口，位于 DSH 内容和控件后面，不拦截鼠标、键盘或滚动事件。
- 开启插件时应用配套深色调色板，并将必要面板调整为合适的半透明深色表面；文字、边框、选中状态及输入焦点保持足够对比度。
- 关闭插件时移除动画和样式覆盖，恢复用户原有的 DSH 外观设置。
- 提供开关与动效强度调节；窗口隐藏时暂停绘制，响应系统“减少动态效果”设置，并适配窗口尺寸变化及高像素密度屏幕。
- 尽量使用 DSH 当前版本公开的插件接口，不修改 DSH 源码，不依赖远程视频或图片资源。

## 实现前核对

已获取官方 `dsh-v0.2.1-rc.3` 源码并按此版本开发。插件清单把 `engines.dsh` 固定为 `0.2.1-rc.3`；扩大版本范围前需在新版本重新核对插件装载、主题服务、设置入口和界面背景层级。
